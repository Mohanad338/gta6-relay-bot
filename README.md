# بوت GTA6AR Relay

ينقل المنشورات من قناة `@GTAVIStar` إلى قناتك `@GTA6AR`، مع إعادة صياغتها بالعربي وإضافة رابط قناتك على كل منشور.

## خطوات الإعداد

### 1. أنشئ بوت جديد
كلّم [@BotFather](https://t.me/BotFather) → `/newbot` → احفظ الـ **token**.
ثم أضف هذا البوت كأدمن في قناة `@GTA6AR` (صلاحية نشر الرسائل كافية).

### 2. مفتاح Gemini
أنشئ مفتاح API جديد من [Google AI Studio](https://aistudio.google.com/apikey) (نفس الحساب المستخدم بالبوتات الثانية أو حساب جديد).

### 3. أنشئ ريبو GitHub جديد
ارفع هذا المجلد كامل إلى ريبو خاص جديد (مثلاً `Mohanad338/gta6-relay-bot`).

### 4. أضف الأسرار (Secrets)
من إعدادات الريبو: `Settings → Secrets and variables → Actions → New repository secret`

| الاسم | القيمة |
|---|---|
| `TG_API_ID` | نفس api_id المستخدم بالبوتات الثانية |
| `TG_API_HASH` | نفس api_hash المستخدم بالبوتات الثانية |
| `TG_SESSION` | نفس السيشن المستخدم بالبوتات الثانية |
| `BOT_TOKEN` | توكن البوت الجديد من BotFather |
| `GEMINI_API_KEY` | مفتاح Gemini الجديد |

### 5. شغّله
البوت يشتغل تلقائيًا كل 5 دقائق عبر GitHub Actions. أول تشغيل ينشر آخر 5 منشورات من قناة المصدر، وبعدها ينشر فقط الجديد.
تكدر تشغله يدويًا أول مرة من تبويب **Actions → GTA6AR Relay Bot → Run workflow** للتأكد أن كلشي شغال.

## ملاحظات
- الحالة (آخر رسالة تم نشرها) تُحفظ بملف `state.json` ويتم تحديثه تلقائيًا بكل تشغيل عبر Git commit.
- إذا يظهر خطأ من Gemini، البوت ينشر النص الأصلي بدون إعادة صياغة بدل ما يوقف كليًا.
- الفيديوهات والصور الكبيرة الحجم (فوق حدود تيليجرام) قد تحتاج تعديل بسيط إذا واجهتك مشكلة برفعها.
